DuckTable design

token-driven mockups — switch the theme, every screen follows

Main window

Three panes: berths + catalog + notebooks sidebar, tab strip, data grid with a staged edit, Details inspector, status line.

Editing

Three LIVE-mode indicator variants, the conflict cell with its resolution popover, and the staged change list.

States

Harbor unreachable, no berths yet, and a berth start failure inline in the sidebar with stderr.

Notebook

Stacked independent query panes: expanded, query-collapsed, and fully collapsed, with the "+" adder between panes.

Every color on every screen resolves through the semantic tokens in tokens.css: five themes (light, dark, paper, midnight, contrast) are five token blocks, nothing else changes. The same vocabulary becomes gpui-component theme JSON in the build. The theme picker at top right persists across pages.
